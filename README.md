# User Authentication & Messaging Platform (In Development)

A Symfony 7 web application focused on user authentication and social interaction features. The project serves as the foundation for a future messaging system.

## Features:

- User registration system
- Email verification with confirmation link
- Resend verification email functionality
- User login and logout
- Browse other user profiles
- Secure authentication using Symfony Security

## Tech Stack:

- PHP 8.x
- Symfony 7
- Symfony Security
- Doctrine ORM
- MySQL
- Twig

## Architecture:

- Modular Symfony structure
- Service-based architecture
- Dependency Injection
- Separation of authentication and business logic

## Purpose:

This project demonstrates secure authentication workflows, user management, and the foundation of a scalable messaging system.
